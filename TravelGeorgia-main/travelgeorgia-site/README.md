# TravelGeorgia

საქართველოს ლაშქრობისა და მოგზაურობის ბილიკების საძიებო და დაგეგმვის ვებ-აპლიკაცია. სასწავლო პროექტია, დამზადებული სუფთა **HTML, CSS და JavaScript**-ით (ფრეიმვორკების გარეშე).

## რას აკეთებს საიტი

- აჩვენებს საქართველოს 9 რეგიონის ~18 ლაშქრობისა თუ მოსანახულებელი ლოკაციის კატალოგს
- საშუალებას აძლევს მომხმარებელს, გაფილტროს ბილიკები რეგიონის, სირთულისა და სეზონის მიხედვით, და მოძებნოს საკვანძო სიტყვით
- თითოეული ბილიკისთვის აქვს დეტალების ცალკე გვერდი
- საშუალებას აძლევს ბილიკები დაამატოს პირად „მოგზაურობის გეგმაში" (ინახება ბრაუზერში, `localStorage`-ის საშუალებით) და ნახოს ჯამური მანძილი და დრო
- შეიცავს საკონტაქტო ფორმას JavaScript-ით განხორციელებული ვალიდაციით

## გვერდები

| ფაილი | დანიშნულება |
|---|---|
| `index.html` | მთავარი გვერდი, სტატისტიკა და რეგიონების მიმოხილვა |
| `catalog.html` | ყველა ბილიკის კატალოგი ფილტრებითა და ძიებით |
| `details.html` | კონკრეტული ბილიკის დეტალები (`?id=` პარამეტრით) |
| `plan.html` | მომხმარებლის მიერ შენახული მოგზაურობის გეგმა |
| `contact.html` | საკონტაქტო ფორმა ვალიდაციით |

## ტექნოლოგიები

- **HTML5** — სემანტიკური მარკირება
- **CSS** — Flexbox/Grid, responsive დიზაინი, CSS ცვლადები
- **JavaScript (ES6+)** — DOM მანიპულაცია, event handling, `localStorage`, URL პარამეტრების დამუშავება

## მონაცემები

ბილიკების მონაცემები ინახება `js/data.js`-ში, JS მასივის სახით (`TRAILS`), რათა საიტი პირდაპირ ფაილიდანაც გაეშვას ბრაუზერში (`file://`), fetch/CORS-თან დაკავშირებული პრობლემების გარეშე. იგივე მონაცემები დუბლირებულია `data/trails.json`-ში, საჭიროების შემთხვევაში სერვერზე განთავსებისთვის.

## გაშვება

საკმარისია `index.html` ფაილის ბრაუზერში გახსნა. რეკომენდირებულია გამოყენება რაიმე მარტივი ლოკალური სერვერის საშუალებით (მაგ. VS Code-ის Live Server გაფართოება), თუმცა ეს არ არის სავალდებულო.

## სტატუსი

პროექტი მუშავდება ეტაპობრივად, კურსის დასრულების ვადებში. იხილეთ commit-ების ისტორია პროგრესის სანახავად.
